# Poker Online

- Jogo de Texas Hold'em No-Limit no navegador (Node.js, Express, Socket.io), com bot que decide pela API do Claude. Código nesta pasta; especificação em `GAME_SPEC.md`.
- Repositório **público** (`poker-online`), vitrine para um processo seletivo: nada de estado de trabalho, dado de terceiro ou segredo no git (`ESTADO.md`, `briefings/`, `dados/` e `.env` estão no `.gitignore`).
- Código se escreve no Claude Code do VS Code; o chat do app conversa, documenta e gera o prompt (P17).
- Estado e pendências: `ESTADO.md`. Regras gerais: `~/Desktop/Projetos/Pessoal/CLAUDE.md`.
